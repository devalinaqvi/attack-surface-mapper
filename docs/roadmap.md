# Roadmap

- **0.1 — implemented:** Composer metadata and graph, direct/transitive context, root hooks and plugins, local native artifact detection, evidence/confidence, text/JSON CLI, safe bounded reads, adversarial tests.
- **0.2:** structured network/subprocess/filesystem detectors, FFI and richer native analysis, custom installer paths, content/version verification, safely bounded metadata fetching and archive inspection, caching.
- **0.3:** Laravel route/controller discovery, application call/reachability graph, evidence-backed internet exposure and attack paths.
- **0.4:** explicit user-defined policy, CI enforcement, SARIF, GitHub integrations, report comparison.
- **0.5+:** npm/PyPI adapters and content locators, provenance, historical capability diffs, shared analysis integrations.

Each stage must preserve the distinction between capability, vulnerability, reachability, and maliciousness. Additional integrations and AI are not prerequisites for analysis.
